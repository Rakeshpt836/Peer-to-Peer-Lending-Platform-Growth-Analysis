# Peer-to-Peer Lending Platform Growth Analysis

## Project Overview

This project analyzes the growth of a peer-to-peer lending platform using loan, borrower, funding, repayment and risk-related data.

The analysis was performed using Python, Pandas, SQL and Power BI.

## Dataset

- Total Records: 2,008
- Records After Cleaning: 2,000
- Columns: 16
- Data Period: 2021 to 2025
- Duplicate Records Found: 8

## Tools Used

- Python
- Pandas
- Matplotlib
- SQL
- MySQL
- Power BI

## Python Analysis

The Python analysis covered:

- Data inspection
- Missing value analysis
- Duplicate checking
- Data cleaning
- Loan analysis
- Funding analysis
- Risk analysis
- Default analysis
- Year-wise loan growth
- Data visualization

## SQL Analysis

A total of 10 SQL queries were used to analyze:

- Total loans
- Total funded amount
- Average loan amount
- Highest loan amount
- Loan status
- Loan purpose
- Average interest rate
- Year-wise loan growth
- Risk grade
- Default rate

## Power BI Dashboard

The dashboard contains 4 KPI cards:

- Total Loans
- Total Funded Amount
- Average Loan Amount
- Default Rate

It also contains 6 charts:

- Loan Growth by Year
- Funding by Loan Purpose
- Loan Status Distribution
- Risk Grade Distribution
- Funding by City
- Default Rate by Risk Grade

## Key Business Insights

- The lending platform has 2,000 loans after data cleaning.
- Total funded amount is around Rs. 510.23 million.
- Average loan amount is around Rs. 267,830.
- Loan activity increased from 2021 to 2025.
- Debt Consolidation has the highest number of loans.
- Completed loans are the largest loan status category.
- Risk Grade B has the highest number of loans.
- Overall default rate is around 4.25%.
- Funding levels differ across borrower cities.
- Loan funding increased over the analyzed period.

## Conclusion

The analysis provides an overview of lending growth, funding patterns, loan purposes, borrower locations and risk levels across the platform.
